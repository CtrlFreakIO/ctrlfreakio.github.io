**Type:** Industrial automation project
**Platform:** Siemens BMS/SCADA

Modified the Building Management System (BMS) control program for air handling units (AHU) serving a designated building section, in response to updated process/technical guidelines for air preparation. Work was carried out on an existing, operational BMS installation within a validated pharmaceutical manufacturing environment.

Prepared a detailed change log for the SCADA integration team, documenting all program changes to support review, approval, and implementation within the site's change control process. Performed functional testing of the modified control logic in simulation to confirm correct operation of the AHU sequences and compliance with the updated guidelines prior to release into the validated environment. Prepared internal test protocols documenting the test scope, steps, and results.

**Key aspects:**
- Modification of existing BMS/AHU control logic based on updated air handling guidelines
- Change impact analysis and preparation of a detailed change log for the SCADA team
- Functional testing of modified control sequences in simulation, with internal test protocols
- Work within an established change control process for a validated pharmaceutical facility
- Coordination with SCADA integration team for implementation and sign-off
